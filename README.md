# getkenner.com

Static site served by GitHub Pages from `main` (custom domain in `CNAME`, keep that file). No build step, no backend, no cookies or analytics; fonts load from Google Fonts.

## Run locally
    python3 -m http.server 8765
    # open http://localhost:8765

## Structure
- `index.html`: the homepage, all markup, CSS and JS inline
- `legal.html`: imprint and privacy policy (`#imprint`, `#privacy`)
- `brand/`: logo lockups, mark and Kenner's profile picture
- `photos/`: industry photos
- `media/`, `demo/`, `light/`: chat media, demo app screenshots and light backgrounds
- `logos/`: integration and team logos
- `app/`: the walk-in cooler work order page captured from the Kenner web app for the service report laptop, generated by `tools/` (do not edit by hand)
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `og-image.jpg` (link preview, 1200x630)

## Regenerate the work order page
The service report's laptop shows `app/work-order.html`: Kenner's real work order page for WO-RF-2047, rendered by the web app with scripted report, actions and knowledge for each stage of the conversation.
Regenerate it when the app's work order page changes:

1. In `kenner-demo` (checked out beside this repository), start a local Kenner on the commercial refrigeration release: `npm run local -- start --template <refrigeration template>`.
2. Capture the four stages with its `Open` link: `node tools/capture-work-order.mjs <Open link> <capture dir>`.
3. With that server still running, build the page: `python3 tools/assemble-work-order.py <capture dir> .`
